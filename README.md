# Console Search Wiki

Консольная программа для поиска статей в русской Википедии. Пользователь вводит запрос, выбирает статью из списка, и она открывается в браузере.

## Пример работы

    Введите поисковый запрос (exit для выхода): c++
    Найдено статей: 10

    1. C++
        Embarcadero (Borland) C++ Builder и другие. C++ оказал огромное влияние на другие языки программирования ...

    2. C. C. Catch
        C. C. Catch (Си Си Кетч (Кэтч); настоящее имя — Кароли́на Катари́на Мю́ллер ...

    Выберите номер статьи (от 1 до 10, 0 — новый поиск): 1

## Запуск

Требуется Java 21 и Maven. Открыть проект в IntelliJ IDEA и запустить класс `Main`.

## Структура

| Пакет | Ответственность |
|---|---|
| `input` | чтение и проверка пользовательского ввода |
| `api` | запрос к MediaWiki API |
| `parser` | разбор JSON-ответа (Gson) |
| `model` | модели ответа (records) |
| `output` | вывод результатов в консоль |
| `browser` | открытие статьи в браузере |

## Подходы

- Зависимости передаются через конструктор и собираются в `Main`.
- Strategy для открытия браузера: `DesktopBrowserOpener` или, если `Desktop` недоступен, `ConsoleLinkPrinter`, который выводит ссылку.
- Ошибки сети и разбора заворачиваются в собственные исключения, программа не завершается аварийно.

## Технологии

Java 21, Maven, Gson
